# Terrapedia

Wiki 2.0 do Terraria: o conteúdo da [Terraria Wiki](https://terraria.wiki.gg) com uma interface
moderna, escura e feita para celular e PC (PWA).

Futuro: busca em português, favoritos e árvores de crafting. Veja [CLAUDE.md](CLAUDE.md).

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:5173.
